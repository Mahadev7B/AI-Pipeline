# Incidents

Evidence from failed Idea Desk evaluations, sent here **by the Founder, deliberately**.

When an evaluation fails, the Idea Desk writes everything the company actually
said — the roster reply, each role's full reading, the Chief of Staff's answer,
and any reformatting attempt — to `ops/idea-desk/diagnostics/`. That folder is
gitignored, because those files contain the Founder's idea in their own words
and the agents' complete output. They are the Founder's to publish or not.

A file only appears **here** when the Founder pressed *Send this to the build
side* on the failure banner and confirmed, having first read the whole file on
screen. The app shows exactly what would be published before publishing it,
because git history does not forget and there is no unsend.

## Why these files exist

Without them, a technical failure could only reach whoever fixes it by the
Founder finding a path in a folder, describing what they saw, and carrying the
text somewhere. That makes the Founder the defect router, which is the wrong job
for them. These files are the evidence arriving on its own.

## What is *not* automatic

Nothing here is written without the Founder starting it. The app does not push
on failure. That is deliberate — publishing to a remote repository is an
irreversible outward action, and this project's standing rule is that those
belong to the Founder.
