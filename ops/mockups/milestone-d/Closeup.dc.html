Progress Closeups — readiness & paused pill

Closeups — two specific design calls

Not a new page — three isolated comparisons zoomed in for the review: (1) how the two readiness booleans should render, (2) what color the new "paused" status pill takes, (3) whether one level of tree nesting reads clearly with no accordion/JS.

1. Readiness booleans — three treatments compared

A — stark boolean only
NOUI 100% complete
YESTesting ready
Rejected
A bare "NO" answers nothing about how close — the Founder's own recurring complaint was not being able to see progress, and this treatment hides the one number (3 of 4) that makes "NOT YET" legible instead of alarming.
B — full narrated sentence
The Founder-facing UI is not yet 100% feature-complete because one of the four planned UI Completeness milestones, Milestone D (Project/Phase Progress), remains in progress as of this writing.
However, exploratory Founder testing may already begin, since Milestones A, B, and C are all complete.
Rejected
Exactly the "narrated" language CTO's own spec forbids (Part 3.4) — invites drifting into softened or hedged phrasing over time, the same failure mode this whole milestone exists to close.
C — recommended: pill + one honest clause
NOT YETUI 100% complete — 3 of 4 done
YESTesting ready — A+B+C done
Recommended
Matches CTO's own Part 4.2 spec almost verbatim. A plain boolean word (never invented adjectives like "nearly") plus the one real fraction that makes it legible — informative, not alarmist, same bar as Milestone A's staleness badge.

2. The new "paused" status pill — color options against this project's existing semantics

Existing convention, confirmed against generate_overview.py/generate_risks.py: green=done/passed, accent(amber)=active/in_progress, red=open risk/danger/founder-action-needed, gray=neutral/not_started, blue=agent "waiting", violet=reserved for the AI-actor/human-actor marker and cross-cutting alert strips (never a status).
Red
paused
Rejected
Red already means "open risk" / "Founder action urgently needed" everywhere else in this product. A Founder-directed pause (DEC-008) is not a danger signal — using red here would misrepresent a deliberate, calm decision as an alarm.
Violet
paused
Rejected
Violet is reserved for "AI actor" / "human actor" identity and the cross-page "needs attention" callout strip (phase-0, Risks). Reusing it for a status value would blur an established, unrelated meaning, not extend it.
Blue — recommended
paused
Recommended
Blue already means "waiting" for agent status on Overview — temporarily halted, not urgent, not active. "Paused" is the same idea one level up (a phase, not an agent run). Extends an existing convention by exactly one value, per CTO's own framing, rather than inventing a fifth color family.
