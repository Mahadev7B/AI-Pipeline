# Control Center Mockups — Phase 0

Three real, substantially different UI concepts for the Agent Control
Center, produced via the `design` skill. Published as one multi-artboard
canvas — an Artifact, not application code:

**https://claude.ai/code/artifact/57fcb90b-fc73-4182-8a3a-12b70cadf39d**

(Private by default — share it from the page's share menu if you want
someone else to open the link.)

## What's here

The source `.dc.html` artboards and `canvas.json` layout the artifact was
built from, kept for the record and for re-seeding a future edit:

- `Main.dc.html` — **Variant A, Pipeline First**
- `AgentFirst.dc.html` — **Variant B, Agent First**
- `CommandCenter.dc.html` — **Variant C, Command Center** (includes the
  Executive Discussion panel)
- `canvas.json` — lays the three artboards side by side on one canvas

These are static mockups (not a clickable prototype), using sample/
placeholder data only (the `TASK-001`–`TASK-005` pipeline example, a
sample Founder Inbox item, a sample Executive Discussion on PDF support).
No real task data, no real founder decision.

## Aesthetic direction (assumption stated, not confirmed with the Founder)

Dark "operating console" theme — near-black panels, a single warm-amber
accent for active/working states, `Space Grotesk` for display type paired
with system-ui body text and a monospace for task IDs/status codes.
Chosen to read as "AI company command console," not Jira/Excel/generic
admin. If the Founder wants a different direction (light theme, different
accent, different type), that's a Phase 0 revision, not a Phase 1
concern.

## Founder vs. CEO Agent

Every artboard marks the Founder with a solid violet avatar labeled
"FOUNDER · HUMAN" and the CEO Agent with a dashed hexagon avatar labeled
"CEO AGENT · AI ADVISOR" — never the same visual treatment, never merged.

See `../../MOCKUP_CRITIQUE.md` for the critique of all three and the
recommendation.
