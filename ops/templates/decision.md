# Decision Template

Append a new entry to `DECISIONS.md` using this shape. Never edit or delete
a prior entry to reverse it — propose a new one instead.

```
### DEC-<NNN> — <short title>
Date:
Problem:
Options considered:
Decision:
Reason:
Tradeoffs:
Agent recommending it:
Founder approval:           (required/not required — and outcome once resolved)
```
