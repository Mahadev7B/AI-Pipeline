# Founder Approval Template

Use whenever an agent hits one of the escalation triggers in `PROJECT.md`
("Founder approval rules"). Post to `/ops/approvals/PENDING.md`; move to
`RESOLVED.md` once decided.

```
FOUNDER APPROVAL REQUIRED

Request:
Requested by:
Why:
Recommendation:
Alternatives considered:
Expected cost:
Risks:
Consequence of not approving:

Decision:  [APPROVE]  [REJECT]  [DISCUSS]
```
