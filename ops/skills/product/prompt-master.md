```
Skill name: prompt-master
Purpose: Generate an optimized, tool-specific prompt from a rough idea.
When to invoke: Product turning a rough idea into a precise brief; Orchestrator preparing precise handoff instructions for another agent or external AI tool.
Inputs required: The rough idea/goal and (if not obvious) the target AI tool.
Analysis/checklist: Confirms target tool; extracts task/format/constraints/context/audience/success-criteria as needed.
Expected output: A single copyable, tool-optimized prompt.
Failure conditions: Target tool genuinely ambiguous and unresolved after asking.
Limitations: Produces a prompt for someone/something else to run — it does not execute the task itself.
Which agents may use it: Orchestrator Agent, Product Agent.
Version: as installed in this environment, 2026-08-28.
```
